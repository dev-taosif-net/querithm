- Choose how several result sets show: Tabs (as before), Stacked (like SSMS) or Side by side. Set the default in Settings, change it per tab from the command palette, maximize one stacked set (Esc returns), and pin a set so it stays while you run the query again.
- "Export all result sets" saves every set at once: one file per set, or one XLSX file with a sheet per set.
- The New connection page is redesigned: pick the engine from tiles or paste a connection string, then fill Connection, Sign in, Profile and Advanced in one scrolling form with a fixed header and footer. Errors show next to the field they belong to.
- Switching the engine while editing a connection no longer keeps the previous engine's default user and database.
- An empty connect timeout no longer saves as "wait forever".
- After a query is cancelled on MariaDB, the next run no longer fails with a stale warning.
- The object tree no longer keeps showing an old view after a refresh that ran while it was loading.
