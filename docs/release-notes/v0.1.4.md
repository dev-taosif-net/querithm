- Oracle Database joins SQL Server, PostgreSQL, MySQL / MariaDB, SQLite and DuckDB. Connect with a service name over TCPS (the default; plain TCP is offered with a warning), directly or through SSH, or paste an Easy Connect string or a descriptor to fill the connection in. Then run SQL and PL/SQL blocks with DBMS_OUTPUT in Messages, browse tables, views, packages, triggers, sequences and synonyms, and use completion and signature help, execution plans, grid editing, import, scripting, schema and data compare, find usages and rename, and the activity monitor (where the account may read V$SESSION). A feature Oracle or your account lacks says why.
- Oracle is not available on Intel Macs: its driver has no build for them, so the engine is listed but disabled with that reason.
