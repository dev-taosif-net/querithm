Smarter autocomplete

- Suggestions you pick often now come first. Querithm remembers what you accept in each database and ranks those items higher next time.
- Tables in the suggestion list show their row count, so you can tell a big table from a small one before you pick it.
- Synonyms, temporary tables and table functions have their own icons in the list.
- SQL Server: temporary tables (#temp) and table variables (@t) declared earlier in the script now suggest their columns.
- Enter no longer grabs a keyword by surprise. After typing something like "FROM t o " or "a, ", Enter starts a new line as you expect.
- Large schemas (thousands of tables) keep the list responsive: the sidecar sends only the items that match what you typed, at most 500. Measured on a 10,000-table schema, each answer drops from about 1.8 MB to about 90 KB.
- While the schema is loading, fails to load or the server is disconnected, the first row of the list tells you so.

Hover help

- Hovering over a column shows more detail about it, in a cleaner style that matches the suggestion list.

Tabs

- New Tab layout setting (Settings › Tabs): Single line (the default), Numbered, Two lines, or Guard rail, which writes PRD and STG out in full on the tab.
- New query tabs are named Query1, Query2, … instead of SQLQuery1.
- Environment badges in the top bar now all have the same width.

Production safety

- New setting: Settings › Query execution › "Confirm before running on production". It is on by default. If you turn it off, queries, destructive statements, grid edits and imports run on production without asking, and the setting shows a warning while it is off. The check runs in the background service, not only in the window.

Connections

- Password fields have an eye button to show or hide what you typed.

Grid editing

- SQL Server: results of queries that name the database in front, like "SELECT TOP 1000 … FROM Sales.dbo.Orders" (the query SSMS writes for "Select Top 1000 Rows"), can now be edited in the grid. Before, they opened read-only.
- DuckDB: the same now works for names written as catalog.schema.table.

Small changes

- The "Explain" button and menu are now called "Plan".
