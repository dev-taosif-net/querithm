Connection groups

- You can now put connections into groups. Use "Move to group…" on a server, or "Manage groups…" to create, rename and delete groups.
- With "Show groups" on (the default), grouped connections appear under their group in the Object Explorer and in the Connect dialog. Connections without a group stay where they were.
- To move many connections at once, choose Organize › Select profiles… in the Connect dialog, tick them, and move them to a group.
- A group never changes a connection's environment. Production connections stay marked red everywhere, and the production checks still apply.
- Deleting a group never deletes its connections. They just become ungrouped.

Connect dialog

- The dialog has a new, cleaner layout with one line per connection.
- It opens on the connection you used last, instead of the first one in the list.
- The bottom of the dialog shows what Enter will do, for example "Connect PROD Sales · user@host".
- Search puts the best match first: an exact name, then names that start with what you typed, then everything else.
- Delete is now in each row's ⋯ menu. The confirm message shows the connection's environment, address and group, so you can see what you are about to delete.
- If a connection is not marked Production but its name or server says "prod", it shows a ⚠ warning. You can turn the warning off for that connection.

Connections

- The "Remember password" choice has an info button that explains each option: how long the password is kept, and whether it is saved in your system's password vault or only in memory.
- After you change a connection to point at a different server, database file, login or SSH tunnel, the Object Explorer and autocomplete no longer show the old server's tables.
- SSH: if your private key is protected by a passphrase and you have not entered one, Querithm now asks for the passphrase. Before, it sometimes showed a confusing key error instead.

Window and start screen

- Querithm remembers the size and position of its window when you restart it.
- The start screen now uses your theme, so a dark theme no longer flashes white when the app opens.
- The welcome screen lists every supported engine, including Oracle.

Tabs

- If you close all tabs and open a new query, it opens on the server and database you used last.

Editor

- Autocomplete: when your query has one table with an alias, like "FROM emp e WHERE id", picking a column now writes "e.id".

Object Explorer

- "Refresh databases" on a server now also refreshes the tables and columns of every database you have already opened on it.

Results grid

- Edit now appears on a table you just created, and on a query that returned no rows. After each run, Querithm checks again with up-to-date table information.
- When a result can't be edited, the reason is clearer. A database with no tables now says so. MySQL: a result from a temporary table now says that MySQL does not list temporary tables.

Production safety

- SQL Server, MySQL and Oracle: if you confirmed the first run on a Production tab before it had connected, the second run asked you to confirm again. It now asks only once, as intended.

Security

- Updated a built-in component of the app window to fix a published security issue (a crash on some specially built web addresses).
