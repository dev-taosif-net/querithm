- The status bar and the tab tooltip show the server address of the connection.
- A query tab widens to show the full database name.
- IntelliSense suggests tables and columns in more places, such as inside CASE expressions and UPDATE statements, and keeps the cached schema when a reload fails.
- Grid editing refuses queries whose result rows cannot be traced to one table, with a reason, on every engine. Undo of many rows runs as one step, and new rows say which required fields are empty.
