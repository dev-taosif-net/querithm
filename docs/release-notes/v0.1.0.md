First release of the new Querithm line. If you used an earlier build, uninstall it and install this one: earlier builds do not update to it.

- Engines: SQL Server, PostgreSQL, MySQL / MariaDB, SQLite and DuckDB. A SQLite or DuckDB database is a file you pick, read-only until you choose Allow writes…, or an in-memory database that lasts as long as its tab. A feature an engine does not have stays in its place and says why.
- Editor with IntelliSense and parameter hints for every engine, snippets, formatting, Find usages and Rename.
- Results grid with editing, import (CSV, JSON, XLSX) and export; charts (Ctrl+2) and a cell viewer for JSON, XML, binary values, images and plans.
- Execution plans, schema and data compare, and SQL notebooks (.sqlbook).
- Activity monitor for SQL Server, PostgreSQL and MySQL / MariaDB: sessions, blocking, waits, top queries and deadlocks.
- Connections over TLS by default and through SSH tunnels; passwords stay in the operating system's credential store. Production connections ask before writes.
- In-app updates, signed with a new key.
