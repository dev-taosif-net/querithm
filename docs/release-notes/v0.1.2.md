- Saved passwords and SSH secrets stay tied to the connection they belong to. Editing a connection retires its old secrets, and a profile cannot overwrite another one's keyring entry.
- Logs and error messages hide more kinds of secrets, on every engine.
- Dialogs, side panels, tabs and settings pages open with short animations, and slow work shows a loading indicator.
- The result grid scrolls smoothly.
- On Windows the Querithm engine is no longer a compressed self-extracting file and carries its name, publisher and version.
- A SQL Server connection test to a wrong or silent address no longer makes other SQL Server connections fail with "too many simultaneous non-pooled connection attempts".
- Closing a dialog returns the keyboard to the editor that opened it.
- Deleting a connection right after its query finished no longer reports it as busy.
- Logs hide a token's value even when a saved secret appears inside its name.
